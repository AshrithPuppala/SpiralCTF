Title: Fragments
Category: Forensics / Steganography / Signals
Difficulty: Medium–Hard Points: 350

Description:

We seized a staging folder from a suspected dead-drop operator. Nothing in it looks important: a banner, a poster, a web page, an audio clip, an archive and a source repository. But the operator was careful, and nothing in the folder is stored the way it appears.

Our analysts believe the folder is one message split into pieces. Every file is carrying something it shouldn’t. Some pieces are easy to find and others only come out if you stop trusting the file extensions, and a few only make sense once you’ve found something else first. Put the pieces back together in the right order and you’ll find out where the operator wanted you to go.
